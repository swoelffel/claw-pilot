# Pilot Interface

The Pilot is the full-featured chat interface for interacting with an agent in real time. It provides a message stream with streaming responses, tool call visualization, delegation cards, and a context sidebar.

## Route

`#/instances/:slug/pilot` — opens the pilot interface for the specified instance.

## Message Stream

The central panel displays the conversation as a scrolling message list. Messages are rendered in real time via SSE (Server-Sent Events) with 22 event types for granular updates.

### Message Types

| Type | Display |
|---|---|
| User text | Right-aligned bubble with plain text or markdown |
| Assistant text | Left-aligned bubble with rendered markdown (code blocks, tables, lists) |
| Reasoning block | Collapsible section showing extended thinking content |
| Tool call | Expandable card showing tool name, parameters, and result |
| Suggestion chips | Clickable quick-reply buttons below the assistant message |
| Delegation card | Expandable card showing subagent work (agent name, prompt, result) |
| Error message | Red-bordered bubble with error details |

### Streaming Behavior

Responses stream token-by-token via SSE. The `message.part.delta` event delivers incremental text chunks that are appended to the current message bubble. Streaming indicators (animated dots) show when the agent is generating a response.

| SSE Event | Purpose |
|---|---|
| `message.created` | New message started (allocate bubble) |
| `message.part.delta` | Append text chunk to current bubble |
| `message.updated` | Message complete (finalize rendering) |
| `tool.call.started` | Show tool call card (loading state) |
| `tool.call.ended` | Update tool call card with result |
| `permission.asked` | Show permission overlay dialog |
| `question.asked` | Display question with clickable options |
| `suggestions.generated` | Render suggestion chips |
| `session.status` | Update session status indicator |
| `budget.soft_alert` | Show budget warning banner |

## Input Bar

The input area at the bottom of the pilot screen.

| Element | Description |
|---|---|
| Text input | Multi-line text field with markdown support |
| Send button | Submit the message (Enter or click) |
| Suggestion chips | Quick-reply options generated by the agent |
| Attachment button | Attach files to the message |
| Model selector | Override the model for the next message |

## Context Panel (Sidebar)

The right sidebar provides contextual information about the current agent and session.

| Section | Content |
|---|---|
| Agents list | All agents in the instance with role badges, click to switch |
| Tools list | Available tools for the active agent (from tool profile + plugins) |
| System prompt | Collapsible view of the current system prompt content |
| Session events | Live event feed filtered to the active session |
| Cost gauges | Token usage and cost meters (session total and budget remaining) |

The sidebar can be collapsed to maximize the message stream area.

## Reasoning Blocks

When the model produces extended thinking (reasoning) content, it is displayed in a collapsible section above the assistant's response text. The section header shows "Reasoning" with a toggle arrow. Collapsed by default after streaming completes.

## Tool Call Cards

Each tool invocation is rendered as an expandable card within the message stream.

| Card Element | Description |
|---|---|
| Tool name | Header badge (e.g., "bash", "read", "grep") |
| Parameters | Collapsible JSON view of the tool call parameters |
| Result | Tool output (text, file content, command output) |
| Duration | Execution time in milliseconds |
| Status | Success (green) or error (red) indicator |

## Delegation Cards

When an agent delegates work to a subagent, a delegation card appears in the message stream.

| Card Element | Description |
|---|---|
| Subagent name | Name and role of the delegated agent |
| Prompt | The instruction sent to the subagent |
| Result | Subagent response (expandable) |
| Tokens/cost | Resource usage for the delegation |

## Permission Requests

When a tool call triggers an "ask" permission rule, an overlay dialog appears.

| Dialog Element | Description |
|---|---|
| Tool name | Which tool is requesting permission |
| Scope and pattern | What resource the tool wants to access |
| Allow button | Permit this tool call |
| Deny button | Block this tool call |
| Remember checkbox | Persist the decision as a permanent rule |

## Session Selector

The session dropdown in the header allows switching between agent sessions within the instance. Each agent's permanent session is listed, along with any active ephemeral sessions. Switching sessions loads the corresponding message history.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| Enter | Send message |
| Shift+Enter | New line in input |
| Escape | Cancel streaming response |
| Ctrl+K / Cmd+K | Open command palette |
