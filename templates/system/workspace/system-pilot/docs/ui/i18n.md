# Internationalization (i18n)

ClawPilot supports 6 languages in the dashboard UI. All user-facing strings are localized using the @lit/localize library with runtime dynamic loading. Agents respond in the user's preferred language regardless of the UI language setting.

## Supported Languages

| Code | Language | Status |
|---|---|---|
| `en` | English | Default, source locale |
| `fr` | French | Fully translated |
| `de` | German | Fully translated |
| `es` | Spanish | Fully translated |
| `it` | Italian | Fully translated |
| `pt` | Portuguese | Fully translated |

## Implementation

### @lit/localize

The dashboard uses `@lit/localize` in runtime mode. Translation bundles are loaded dynamically when the user switches language, without a full page reload.

| Aspect | Detail |
|---|---|
| Library | `@lit/localize` with runtime locale switching |
| Source locale | `en` (English) |
| Bundle format | JavaScript modules in `ui/src/localization/` |
| String extraction | `@lit/localize-tools extract` from `msg()` calls in Lit templates |
| Build integration | Translation bundles built alongside UI components by Vite |

### String Tagging

All UI strings use the `msg()` function from `@lit/localize`:

```typescript
html`<p>${msg("No instances found")}</p>`
```

Strings with dynamic values use `str()` for interpolation:

```typescript
msg(str`${count} agents running`)
```

## Language Switching

Users set their preferred language in the User Profile settings screen. The selection is persisted in the `user_profiles` table (`language` column) and takes effect immediately without page reload.

| Step | Detail |
|---|---|
| User Profile | Settings page includes a language dropdown |
| Persistence | Stored in `user_profiles.language` column |
| Detection | On first visit, browser `Accept-Language` header determines default |
| Fallback | If browser language is unsupported, defaults to English (`en`) |
| Session scope | Language preference is per-user, not per-browser |

## Date and Time Formatting

All dates and times in the UI are formatted using the `Intl.DateTimeFormat` API, respecting the user's selected locale. Relative times (e.g., "5 minutes ago") also use locale-aware formatting via `Intl.RelativeTimeFormat`.

| Format | Example (en) | Example (fr) |
|---|---|---|
| Short date | Apr 17, 2026 | 17 avr. 2026 |
| Full date | April 17, 2026 | 17 avril 2026 |
| Time | 2:30 PM | 14:30 |
| Relative | 5 min ago | il y a 5 min |

## Agent Language Behavior

Agents respond in the user's preferred language as detected from the user profile or conversation context. This is independent of the dashboard UI language.

| Aspect | Behavior |
|---|---|
| Response language | Matches user's configured language or conversation language |
| Workspace files | Written in English (SOUL.md, AGENTS.md, docs/) |
| Translation | Agents translate their responses at generation time |
| System prompt | Injected in English; agents produce localized output |
| Skills | Skill output follows the agent's response language |

## Number and Currency Formatting

Numeric values (token counts, costs, budgets) use `Intl.NumberFormat` for locale-aware formatting.

| Value | en | fr | de |
|---|---|---|---|
| 1234567 | 1,234,567 | 1 234 567 | 1.234.567 |
| $12.50 | $12.50 | 12,50 $US | 12,50 $ |
| 95.3% | 95.3% | 95,3 % | 95,3 % |

## Adding a New Language

To add a new language to the dashboard:

1. Add the locale code to the `targetLocales` array in `ui/lit-localize.json`
2. Run `@lit/localize-tools extract` to generate the XLIFF translation file
3. Translate all strings in the new XLIFF file
4. Run `@lit/localize-tools build` to generate the JavaScript bundle
5. Register the new locale in the language dropdown component
6. Add the locale to the `user_profiles` language validation schema

## Translation Coverage

All UI screens and components are fully translated. This includes:

- Navigation labels and menu items
- Form field labels and placeholders
- Error messages and validation text
- Confirmation dialogs and action buttons
- Status badges and state labels
- Notification titles and descriptions
- Tooltip text and help content
