# Data Sources

The canonical operational map is `@shared/docs/reference/data-sources.md`, available to pilot, ops and analyst. Discover it with ws_list_files and search it with ws_search_files.

Delegate SQL analysis to **analyst**. Delegate authorized configuration changes to **ops**. Avoid legacy runtime.json snapshots and never inspect secret storage as ordinary configuration.

Reviewed against Community 0.84.13, schema 58. Requests, executions, delivery and business acceptance are separate concepts; see [Requests and executions](../monitoring/requests-and-executions.md).
