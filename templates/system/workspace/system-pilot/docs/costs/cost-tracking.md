# Cost Tracking Dashboard

The cost tracking dashboard provides visibility into AI spending across agents,
sessions, and models within a ClawPilot instance. Costs are calculated from
actual token usage recorded during LLM calls, not from estimates.

## Data Source

Cost data originates from two runtime tables:

| Table | Role |
|---------------|---------------------------------------------------------------|
| `rt_sessions` | Tracks sessions with their agent, start time, and status |
| `rt_parts` | Records individual LLM call parts: tokens in, tokens out, model, cost |

Each LLM call generates a part record containing `tokens_in`, `tokens_out`, and
`cost_usd`. The cost is computed at call time using the model pricing table for
the provider and model combination used.

## API Endpoint

```
GET /api/instances/:slug/costs
```

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|--------|---------|---------------------------------------|
| `days` | integer| `30` | Time window: `7`, `30`, or `90` days |
| `agent` | string | all | Filter by agent ID |
| `model` | string | all | Filter by model ID |

### Response Structure

The response includes aggregated cost breakdowns:

```json
{
  "total_cost_usd": 142.57,
  "period_days": 30,
  "by_agent": [
    { "agent_id": "research", "agent_name": "Research Agent", "cost_usd": 89.20 },
    { "agent_id": "writer", "agent_name": "Writer Agent", "cost_usd": 53.37 }
  ],
  "by_model": [
    { "model_id": "claude-sonnet-4-20250514", "cost_usd": 120.00 },
    { "model_id": "claude-haiku-4-20250414", "cost_usd": 22.57 }
  ],
  "by_session": [
    { "session_id": "ses_abc123", "agent_id": "research", "cost_usd": 15.40 }
  ],
  "daily": [
    { "date": "2026-04-10", "cost_usd": 4.80 },
    { "date": "2026-04-11", "cost_usd": 6.12 }
  ]
}
```

## Aggregation Views

| View | Description |
|-----------------|---------------------------------------------------------------|
| Total cost | Sum of all LLM call costs in the selected time window |
| Cost per agent | Spending grouped by agent identity |
| Cost per model | Spending grouped by AI model used |
| Cost per session | Spending grouped by runtime session |
| Daily timeline | Day-by-day cost totals for trend analysis |

## Dashboard Visualizations

The cost dashboard in the ClawPilot UI provides three visual components:

### Bar Chart by Agent

Horizontal bar chart showing each agent's total spend in the selected period.
Agents are sorted by cost descending, making the most expensive agents
immediately visible.

### Line Chart Over Time

Time-series line chart plotting daily cost totals. Useful for spotting spending
spikes, identifying trends, and correlating costs with deployment events or
workload changes.

### Detailed Breakdown Table

Sortable table with columns for date, agent, model, session, tokens in,
tokens out, and cost. Supports pagination and filtering. Export to CSV is
available for accounting and audit purposes.

## Usage Tracker

The runtime session usage tracker records granular token metrics for every
LLM interaction:

| Metric | Type | Description |
|-------------|---------|---------------------------------------------|
| `tokens_in` | integer | Input tokens sent to the model |
| `tokens_out`| integer | Output tokens generated by the model |
| `cost_usd` | decimal | Computed cost for this specific LLM call |

These metrics are written to `rt_parts` immediately after each LLM response,
ensuring the cost dashboard reflects near-real-time spending.

## Time Filtering

| Window | Use case |
|------------|-----------------------------------------------------|
| Last 7 days| Short-term monitoring, daily budget validation |
| Last 30 days| Monthly review, budget period alignment |
| Last 90 days| Quarterly analysis, trend identification |

## Notes

- Costs reflect actual token counts reported by the AI provider, not prompt
  length estimates.
- Model pricing is maintained in the provider catalog and updated when
  providers change their rates.
- Sessions with zero cost (e.g., cache hits or tool-only interactions) are
  included in session counts but contribute zero to cost totals.
- The cost tracking system operates independently of budget enforcement;
  costs are recorded even when no budget is configured.
